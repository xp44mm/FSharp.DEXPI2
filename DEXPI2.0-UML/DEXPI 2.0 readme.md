# DEXPI 2.0 Specification: supporting materials files

## Dexpi.xmi

- standard version
- tested with Sparx Enterprise Architect 17

## DEXPI 2.0 EA Information Model.qea

- EA project to open with Sparx Enterprise Architect 16 or later
- includes all DEXPI UML classes + specific diagrams to illustrate the model content

## DEXPI 2.0 EA Information Model.xml

- XMI 1.1 export from the Enterprise Architect project (QEA file, see above)

## DEXPI 2.0 EA HTML export.zip

- HTML export from Enterprise Architect (static site) in a zip archive
- Also available online via DEXPI homepage: <https://dexpi.org/static/ea_dexpi_spec_2.0/>

## Dexpi for Modelio.xmi

- tailored to Modelio
- modified header element
- PrimitiveTypes in DEXPI (Integer, String, ...) have been renamed to Primitive... (PrimitiveInterger, PrimitiveString, ...); otherwise, Modelio confuses them with its builtin UML types
- tested with Modelio 5.4
- tested with Sparx Enterprise Architect 17
